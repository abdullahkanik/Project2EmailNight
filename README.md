# 📧 ASP.NET Core Mail Yönetim Sistemi

Modern bir **E-posta Yönetim Sistemi**, **ASP.NET Core MVC** kullanılarak geliştirilmiştir.  
Kullanıcıların mesajlarını yönetebileceği, yıldızlayabileceği, spam veya çöp kutusuna taşıyabileceği modern bir web uygulamasıdır.

---

## 🚀 Proje Özellikleri

### 📥 Mail Yönetimi
- Gelen kutusu (Inbox)
- Gönderilen mesajlar
- Spam yönetimi
- Çöp kutusu
- Taslak mesajlar

### ⭐ Mesaj Özellikleri
- Mesaj yıldızlama
- Mesaj okundu / okunmadı durumu
- Spam olarak işaretleme
- Çöp kutusuna taşıma
- Mesaj detay görüntüleme

### ✉️ Mail Gönderme
- Rich Text Editor ile mesaj yazma
- Modern compose mail penceresi
- HTML içerikli mesaj gönderimi

### 👤 Kullanıcı Özellikleri
- Profil düzenleme
- Profil resmi yükleme
- Şifre değiştirme
- ASP.NET Identity ile kullanıcı yönetimi

### 📊 Dashboard
Dashboard sayfasında sistem hakkında özet bilgiler:
- Toplam mesaj sayısı
- Okunmamış mesaj sayısı
- Spam mesaj sayısı
- Yıldızlı mesaj sayısı
- Son gelen mesajlar

---

## 🛠 Kullanılan Teknolojiler

### Backend
- ASP.NET Core MVC
- Entity Framework Core
- ASP.NET Identity
- LINQ

### Frontend
- HTML5
- CSS3
- Bootstrap
- JavaScript
- Quill.js

### Veritabanı
- SQL Server

---

## ⚙️ Kurulum

Projeyi klonlayın:

```bash
git clone https://github.com/abdullahkanik/Project2EmailNight.git
```
Visual Studio ile açın:
```bash
Project2EmailNight.sln
```
Migration işlemlerini uygulayın:
```PowerShell
Update-Database
```
F5 ile Projeyi çalıştırabilirsiniz...
